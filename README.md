# Social Links Profile

A responsive social media links profile page built as a Frontend Mentor challenge. Features a clean, modern design with hover effects and mobile-first responsive layout.

![Design preview for the Social links profile](./preview.jpg)

## 🛠️ Built With
- **HTML5** - Semantic markup
- **CSS3** - Custom properties, Flexbox, Grid
- **Responsive Design** - Mobile-first approach

## ✨ Features
- Fully responsive design
- Hover and focus states for interactive elements
- Clean, modern UI design
- Optimized for all screen sizes
- Accessible markup structure

## 🚀 Getting Started

### Prerequisites
- Web browser

### Installation
1. Clone the repository
```bash
git clone https://github.com/SeNaTu24/SOCIAL-MEDIA-LINKS.git
```

2. Navigate to project directory
```bash
cd SOCIAL-MEDIA-LINKS
```

3. Open in browser
```bash
# Simply open index.html in your browser
```

## 📱 Responsive Design
- Mobile: 375px
- Desktop: 1440px
- Fully responsive between breakpoints

## 🎨 Design System
- **Primary Color**: hsl(75, 94%, 57%)
- **Text Colors**: 
  - White: hsl(0, 0%, 100%)
  - Grey: hsl(0, 0%, 20%)
  - Dark Grey: hsl(0, 0%, 12%)
- **Font**: Inter (400, 600, 700)
